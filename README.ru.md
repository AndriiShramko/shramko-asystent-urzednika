Состояние на субботу 21.11, около 13:40. Строим одно: **конвертер бланка в JSON под задание COI «Cyfryzacja formularzy»**. На входе один пустой бланк (PDF, DOC, DOCX, ODS, XLSX, JPG, PNG), на выходе JSON в формате их генератора форм, как сервис в Docker. Идея одной фразой: **компилятор с бухгалтером, а не сканер с ИИ**. Модель внутри продукта не работает: это запрещено условиями задания.

Образ: `ghcr.io/andriishramko/shramko-asystent-urzednika@sha256:d04875554f13ccb92fb83d223b704e62776df8a579814885794b0066b6ff441f`. ## Одна просьба до запуска чата сборки: Docker (около 20 минут и одна перезагрузка)

На ноутбуке нет Docker и нет WSL. Задание требует Docker-образ, а агент поставить их не может: нужны права администратора. Сделай один раз:

1. Открой PowerShell от имени администратора и выполни:

   ```powershell
   wsl --install
   ```

2. Перезагрузи ноутбук.
3. Снова PowerShell от имени администратора:

   ```powershell
   winget install -e --id Docker.DockerDesktop
   ```

4. Запусти Docker Desktop один раз и дождись надписи, что движок работает.
5. Проверь в обычном PowerShell:

   ```powershell
   docker run --rm hello-world
   ```

Если не делать, сборка всё равно идёт: код пишется и проверяется прямо в Windows, а образ при каждом пуше собирает и проверяет GitHub (это медленнее, и доказательство будет ссылкой на прогон, а не запуском у тебя на глазах). Без Docker на защите сервис запускается на ноутбуке напрямую. Примет ли это жюри, зависит от ответа на вопрос J8 анкеты «на каком железе запуск на защите».

Если чат простоял больше часа или стал очень длинным, не буди его: начни новый чат той же фразой. Всё состояние лежит в файле `docs/03-plan/STATUS.md`, новый агент продолжит с места остановки.

## Что можно выключить на время хакатона (необязательно)

Измерено: каждый чат на этом ноутбуке несёт около 68 тысяч токенов ещё до первого сообщения (инструменты, коннекторы, список скиллов). Твои 75 личных скиллов сборке не мешают, трогать их во время события не надо. Если хочешь облегчить главный чат:

1. закрой лишние вкладки браузера и тяжёлые программы: свободной памяти было 2 ГБ из 16;
2. для чата сборки отключи коннекторы, которые ему не нужны (Semrush, Box, Notion, Sheets, Slides, Docs, Drive, Calendar, Hugging Face);
3. на выходные можно выключить плагин `understand-anything`: в файле `C:\Users\<you>\.claude\settings.json`, раздел `enabledPlugins`, поставить `false`; вернуть `true` после события.

Подробно и с числами: `docs/04-orchestration/machine-notes.md`.
