# Shramko Asystent Urzędnika: что это и что делать (для Андрея)

Это репозиторий-задание для главного агента. В нём исследование, требования, решение о том, что строить, план по часам хакатона, готовая презентация и правила работы агентов через git. Кода продукта здесь пока нет: его пишут агенты на хакатоне.

Сайт проекта: <https://urzad.flyreelstudio.eu> · презентация: <https://urzad.flyreelstudio.eu/deck/>

## Что делать утром (три шага)

1. На новом компьютере открой Claude Code и вставь в новый чат:

   ```
   Ты главный агент проекта Shramko Asystent Urzędnika. Открой репозиторий
   https://github.com/AndriiShramko/shramko-asystent-urzednika (клонируй, если его нет),
   прочитай START_HERE.md и действуй по нему. Отвечай по-русски, коротко.
   ```

2. В 11:00 на hacknation.pl/zadania появятся полные условия. Всё, что получишь на месте (листовки, слайды, слова менторов), сфотографируй или перескажи агенту и скажи «new intake». Он сам разложит это по плану.
3. До **18:00 субботы** отправь черновик проекта в HackTribe (крайний срок 20:00, после него задание сменить нельзя). До **10:00 воскресенья** отправь итог (крайний срок 11:00). Тексты для всех полей готовит агент.

Как проходит хакатон, кто судит, что делать по часам и чем зацепить жюри: [`docs/05-hackathon/kak-prohodit-hackathon.ru.md`](docs/05-hackathon/kak-prohodit-hackathon.ru.md).

## Идея одной фразой

**От запроса до ответа на одном движке.** Чиновнику ассистент разбирает запрос, считает сроки и готовит проект ответа с проверенной статьёй закона. Жителю тот же движок превращает бумажный бланк в онлайн-форму и сразу показывает, что ответ уже опубликован. Запросов становится меньше, а те, что приходят, уже разобраны по пунктам. Следующий шаг на том же ядре: данные один раз, бланки заполняются сами. Общим для всех учреждений делаем реестр образцов, а персональные данные остаются у человека.

## Презентация

- Открой <https://urzad.flyreelstudio.eu/deck/> и нажми `F`: это окно для зала.
- Нажми `P`: откроется твоё окно. В нём крупно польский текст для чтения, под ним смысл по-русски, подсказка, следующий слайд, таймер на 5 минут и карточки с ответами на вопросы жюри (клавиши `1`–`9`, `0`).

- Без сети презентация открывается с диска: файл `site/deck/index.html` в папке репозитория.

## Сервер

Поддомен `urzad.flyreelstudio.eu` заведён на твоём сервере. Сервер сам забирает папку `site/` из репозитория каждые две минуты, поэтому с любого компьютера выкладка делается обычным пушем, ключи от сервера не нужны. Программ проекта на сервере не запускаем: там мало места и работают твои боты. Пробные версии выкладываются как статические сборки. Подробно: [`docs/04-orchestration/deploy.md`](docs/04-orchestration/deploy.md).

## Ответы на твои вопросы

- **Можно ли взять данные из mObywatel?** Готовый поток есть с 2020 года: «Przekaż instytucji». Учреждение показывает QR-код, житель сканирует его в mObywatel, видит, какие данные уйдут, и подтверждает. Но открытого подключения и песочницы для него нет, нужен договор с министерством. В демо показываем свой QR-обмен и честно называем подключение mObywatel предложением. Подробно: [`research/04-mobywatel-identity-once-only.md`](research/04-mobywatel-identity-once-only.md).
- **Единая база обо всех для многих учреждений?** Законного основания для такой базы у поставщика нет, а государственные реестры уже существуют. Рабочий путь: данные у человека, учреждению он передаёт только нужные поля; общим делаем открытый реестр образцов бланков.
- **Обязательна ли печать, идентичная образцу?** Бланк прописки это министерский образец, его печатаем на оригинальном файле без перевёрстки: проверка дала ноль отличающихся точек вне полей. Первоисточника о том, что неидентичная распечатка недействительна, не найдено, поэтому слово «юридически идентично» не говорим.
- **Сканер.** Adaptive Recognition Osmond с RFID. Лицензии привязаны к устройству; обновлять программу нельзя, пока не проверен срок лицензии: новая версия может не запуститься. Для продукта нужно согласие производителя.
