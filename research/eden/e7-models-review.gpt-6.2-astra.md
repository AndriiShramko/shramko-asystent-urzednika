1. **`page.py` — `Page`, `Run`.** A DOCX page can contain an ordinary flow paragraph and a positioned text box anchored to that paragraph. Neither `flow` nor `native` accepts both. A `Box` can already extend outside the page; what is lost is the anchor, its reference frame and its offsets. **Change:** make placement per element, not uniform per page. Keep box-only and anchor-only placements; add an anchored-box placement with anchor reference, relative frame and signed offsets. Preserve the resolved box when known rather than inventing page coordinates.

2. **`brief.py` — `BriefField`, `Brief`; `meta.py` — `Ledger`, `Meta`.** F4 knows why a finder candidate was merged, covered by a standard section or omitted, but passes on only a single `BriefField.candidate` and omissions without candidate IDs. F15 must rediscover those decisions. Worse, deleting a candidate’s entire row and decrementing the counts still produces a valid ledger. **Change:** have F4 emit a disposition keyed by finder candidate ID, targeting a brief key, standard role, merge candidate, omission reason or pending decision. Let F5 return the brief-key-to-form-ID map. At assembly, check exact equality with finder candidate IDs and resolve the targets against the actual outputs.

3. **`page.py` — `Run`; `candidate.py` — `Candidate`, `Label`, `ChoiceOption`, `FinderOutput`; `meta.py` — `Coverage`.** `Run.text` can hold `❑ pies ❑ suka`, but a single run box and ID cannot locate its two marks separately, distinguish their labels, or account for four blanks embedded in one sentence. Whole-run references either overlap or make partially understood text look fully covered. **Change:** add a shared `(run_id, start, end)` span with defined character offsets and optional glyph boxes/rotation from the reader. Use spans for marks, labels and options; retain whole-run shorthand. Compute coverage against actual page runs and spans, not just submitted counts.

4. **`brief.py` — `Applicants`, `ApplicantExtra`, `Cond`, `Brief`.** Independent party flags and a shared capacity list cannot distinguish “proxy for a person, representative for an entity” from the reverse. An extra cannot belong explicitly to the person at the keyboard while acting for someone else. A proxy-only attachment condition also fails validation: only matter fields are legal condition targets. **Change:** carry evidenced applicant options as tuples of stable option key, party and applicable capacity; distinguish keyboard-person from party fields. Register the applicant selector and its option keys as condition targets alongside matter selectors. A composite paper can then use one selector and conditional sections without duplicating applicant fields.

5. **`form.py` — `FormField`, `Form`; `meta.py` — `Proposals`.** Strict output accepts any `dictionaryName` on a `SELECT` and arbitrary strings as external defaults, including a keyboard-person source on an entity field. Both F6 negative controls can therefore pass model validation. **Change:** restrict emitted dictionaries to `Kraje`, `TERYT_DOWODOWY`, `TERYT_4G_DOWODOWY`; validate external defaults against the three documented sources at emission, using the brief’s field-owner mapping. Put non-approved bindings in proposals, not the partner tree.

6. **`page.py` — `Run`, `Page`, `Table`.** A DOCX dotted tab can arrive as just `\t`; a footnote reference loses its target; header, footer and column membership disappear even when the source declares them. A stamp-only page can be indistinguishable from an empty page, defeating `SILENT_PAGE`. On anchored sheets, merge spans survive but row heights and column widths do not. **Change:** preserve source-declared tab stops/leader styles, region IDs and kinds, footnote links, placed picture bounds or an ink flag, and optional sheet row/column sizes. These are reader facts; F3 should infer layout only where the source supplies none.

7. **`page.py` — `Widget`; `brief.py` — `BriefField`.** One string per PDF option cannot preserve both its display label and its export value. Radio widgets also need the shared field identity and each widget’s on-state; a visible caption is not the submitted value. At the other end, a single affirmative checkbox with no printed option list is rejected by `BriefField`. **Change:** carry widget field reference, display/export pairs and button states separately; allow an optionless boolean `CHECKBOX` in the brief. Do not manufacture an option from its question label.

8. **`common.py` — `Evidence`; `brief.py` — `BriefField`, `Attachment`, `Consent`; `meta.py` — `Meta`, `FieldEvidence`.** `required_basis="paper"` passes with no evidence, and `inferred` need not produce `REQUIRED_INFERRED`; attachments and consents have no basis at all. Conversely, a drawn blank can have genuine geometric evidence but no honest quote. Meta retains only one evidence record per field, drops run IDs, and accepts a paper field with no evidence entry. **Change:** reuse a list of shared evidence records per field; permit located non-text evidence for blanks while retaining quotes for textual claims. Apply the evidence-or-inferred-warning rule to emitted requirements and check paper-origin fields against the finished form.

9. **`brief.py` — `Brief`, `Declarations`, `Attachment`; `meta.py` — `Receipts`, `Proposals`.** F15 cannot tell whether an empty attachment list means “not found” or “ambiguous”: F4 has nowhere to pass that receipt. A proposed fee has no typed destination separate from the paper fee. `Consent.text` preserves wording, but an affirmative declaration distinct from consent has no corresponding item kind. **Change:** pass the mandatory-attachments `Stated` receipt from F4, keep proposed fees in a separate proposal record, and give verbatim declaration items a `declaration | consent` discriminator. Never upgrade a `not_found` fee to `stated` because of a proposal.

10. **`brief.py` — `BriefField`, `Cond`, `Attachment`, `Consent`; `form.py` — `Option`, `Form.build`.** Field keys and section roles can seed stable IDs, but attachment and consent items lack keys, conditions identify options by visible strings, and `Option.of` explicitly uses display text as ID. A wording correction can invalidate a condition or change an identity. UUID syntax checks alone also accept a fresh random UUID every run. **Change:** assign stable semantic keys to referencable brief items and options, resolve conditions by key, and share one fixed-namespace UUID5 helper for generated nodes and links. Translate to display values only where the partner wire format requires them.

11. **`page.py` — `Run`, `Widget`, `Page`; `common.py` — `Box`.** Passing a source-reported zero font size or zero field length directly to these optional positive fields raises a validation error; reversed raw rectangle endpoints also throw. One bad observation should not discard an otherwise readable page. **Change:** provide reader-boundary constructors that normalize reversed endpoints, omit unusable optional metrics, and record `UNREADABLE_PART` with location. Skip an unplaceable element with a warning rather than fabricate a box. Keep strict validation for converter-generated IDs and references, and controlled 422s for genuinely unreadable or over-limit inputs.

12. **`form.py` — `Tab`, `Form`.** A tab containing one conditional section satisfies `min_length=1` even when that section is hidden on an applicant or variant journey. F5 can thus emit a structurally valid empty page. **Change:** before emitting, check the composed section/component visibility for each supported selector journey using the brief predicates that produced the JSONata states. Move conditional content onto a page that remains usable if the check fails; do not add a dummy field.

**fine as it is**
- `Cell.rs`/`cs`, cell borders and `Page.hidden` already carry merges, border presence and hidden-sheet status.
- `MatterSection.repeating`, `REPEATING_SECTION` and the listed inner component types already cover the requested wire types.
- `State.query` already carries JSONata text; no partner-side condition-tree key is needed.
- `Stated` already distinguishes absence from ambiguity and can retain both conflicting addressee quotes.
- Sorted ID maps and exclusion of resource timings from deterministic meta bytes can stay.
