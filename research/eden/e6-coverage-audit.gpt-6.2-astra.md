3. **B — Defence failure drills.** Each row gives today’s check → fallback.
   1. Skewed low-contrast JPEG loses `ł`, `ą` or checkbox outlines: rotate/fade a labelled page; compare labels and counts → flag page for transcription, not “no fields”.
   2. PDF has text headers but photographed body: test mixed-content page against expected body field → OCR body or mark region unread.
   3. Two-column PDF assigns right-hand PESEL to left-hand applicant: assert label, box and owner together → leave association unresolved.
   4. Floating DOCX text boxes reorder instructions: shuffle XML anchor order without moving boxes; compare section membership → show anchors for inspection.
   5. Binary DOC loses table geometry: check adjacent `wnioskodawca`/`pełnomocnik` names stay distinct → report flow-only ambiguity; 422 if unreadable.
   6. XLSX/ODS merged cells, hidden helper sheet or repeated rows create phantom fields: assert one visible field per labelled merge → omit helpers, flag uncertain grid.
   7. `□ inne (jakie?)` beside a bullet becomes two choices: assert one option plus conditional text → preserve wording, request grouping decision.
   8. Eleven PESEL boxes or `NN-NNN` become separate numbers: assert single string, leading zero retained → plain text without inferred checksum.
   9. `wypełnia organ` or `niepotrzebne skreślić` misread as required resident input: check office block and contrasting slash phrases → quote instruction; no guessed requirement.
   10. Repeating children/attachments table spans pages: repeat header on page two; expect one repeating section, not duplicated mandatory children → flag multiplicity, never silently truncate.
