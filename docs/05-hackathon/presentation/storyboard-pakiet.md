### The opening and the hook (R53, owner's fifth brief)

The owner asked for a start so short that the ideas and the problems are clear at once, and for something unusual and large in scale that holds judges and mentors. The first two pages do that and can be read without the rest.

What is used as the hook, in order of strength, each one true today:

1. **A whole city in advance.** A program read all 661 documents of the city's service cards in 142 seconds and found the places to fill in 461 of them without a model. Nobody asked a clerk for anything. (Measured; `research/13` §1. Always "pierwszy etap", never "gotowe usługi".)
2. **One description, three kinds of user.** The same description of a form serves the resident's phone, the clerk's counter and the resident's own AI assistant. France gave AI assistants an official way to public data; the proposal here is the next step, services, with a person confirming every act. (Verified; `research/13` §2. Never "first in the world".)
3. **One template, 2,479 communes.** The residence template is fixed by a national regulation, so one description fits every commune office. (Verified; `research/13` §3. Only for templates fixed by law.)
4. **Zero changed pixels outside the fields.** The print is the official template, proven by a pixel comparison on the three-page residence form (31 fields). Use it aloud at the demo, when the printed sheet is in the juror's hand.
5. For the stage, not for the PDF: let a juror say a need in their own words, or scan the code with their own phone, and hand them the printed set.

## Technical notes

- `tools/build_pakiet.py` writes `index.html`, `ru.html` and `skrot.html` (plain HTML, CSS and inline SVG, no network, no build step for readers). Edit texts, `BUILT`, `AGENT_DOOR_BUILT`, `METRICS`, `CENSUS`, `WORKS`, `SIMULATED` at the top of the script and run it again.
- PDF: `google-chrome --headless --no-pdf-header-footer --print-to-pdf=docs/assets/deck-pakiet/Od-potrzeby-do-podpisu.pdf docs/05-hackathon/presentation/pakiet/index.html` (each page prints as one 16:9 sheet; motion is off in print; add `--window-size=1280,720`, otherwise the print uses the phone layout). The short version: the same command with `skrot.html` and `Od-potrzeby-do-podpisu-skrot.pdf`. Check the size (limit 10 MB) and the page count against the task card.
- Checking a page without motion (screenshots): open it with `?static=1`.
- Publishing: copy `index.html` to `site-formularze/pakiet/index.html`, add a card on `site-formularze/index.html`, push; the server pulls within two minutes ([`../../04-orchestration/deploy.md`](../../04-orchestration/deploy.md)).
- Before the final submission: open the PDF and read every page once against the software; a page that shows something not built is removed, not defended.
